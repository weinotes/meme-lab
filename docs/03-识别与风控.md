# 03 · 识别与风控：归零类型、链上检查清单与评分卡

> 目的：把"感觉不安全"变成"可以逐条勾选的清单"，用规则压低归零概率。
> 更新日期：2026-10-03。

## 1. 归零的七种死法

按发生频率和杀伤力排序：

| 类型 | 机制 | 信号 |
|:-----|:-----|:-----|
| Rug pull（抽池） | dev 撤走 LP，价格瞬间归零 | LP 未锁/未烧、单一地址持有 LP、流动性极薄 |
| Honeypot（貔貅） | 合约只允许买不允许卖，或卖出触发高额扣款 | 卖出模拟失败、买卖税不对称、合约可疑 |
| 增发砸盘 | mint 权限未放弃，dev 随时印币砸盘 | mint authority 未放弃、供应量可增 |
| Freeze 冻结 | 持有 freeze 权限，可冻结你的账户 | freeze authority 未放弃 |
| 高额买卖税 | 每笔抽走大比例，来回即归零 | 税率 >10%（阈值自定）需极度谨慎 |
| 内部人抛售 | dev/私募/捆绑地址成本近零，随时出货 | 前 10 持币占比高、多个关联地址 |
| 注意力衰退 | 无 rug，但没人接盘，自然阴跌至流动性枯竭 | 社交热度衰减、成交量萎缩 |

前六种可以靠链上检查提前排除，第七种只能靠速度和纪律。

## 2. 硬性检查清单（一条不过就不进）

以下每一项都在链上可查（浏览器 / 风险检测工具 / RPC）。这是"否决清单"，不做加权。

- [ ] **Mint authority 已放弃**（不可再增发）。
- [ ] **Freeze authority 已放弃**（不可冻结持仓）。
- [ ] **LP 已烧毁或已锁定**，且能查到锁仓记录与到期时间。
- [ ] **无高额买卖税**（建议阈值：总税 ≤ 10%；超过直接否决）。
- [ ] **合约可读、无隐藏 owner 提权函数**。
- [ ] **前 10 持币地址占比**在可接受范围（阈值自定，通常越小越安全）。
- [ ] **没有单一地址持有接近全部 LP**。
- [ ] **dev / 内部人持仓比例**不过高，且没有明显捆绑开盘的地址群。
- [ ] **存在双向真实成交**：小额试卖能成功（见下节）。
- [ ] **有真实社交存在**：X/Telegram 是活人，不是几小时前批量注册的空号。
- [ ] **流动性深度**足以承受你的单笔（滑点估算在可接受范围）。

## 3. 蜜罐检测：小额试卖

链上静态检查能排除大部分，但蜜罐最终要靠**动态验证**：

1. 用极小金额买入。
2. 立刻尝试卖出（先卖回绝大部分）。
3. 观察：能否成交？到手金额相对买入是否被抽走异常比例？

**注意**：

- 试卖本身有成本（手续费 + 滑点 + 可能的税），要把这笔计入预算。
- 有些合约会"放过第一笔卖单"，试卖通过不代表安全，仍需结合其他信号。
- 试卖通过后，正式建仓仍要分批，不要一次打满。

## 4. 评分卡设计（把清单变成分数）

清单是"能不能进"，评分卡决定"进多进少"。建议把每个维度映射到 0–5 分，加权求和：

| 维度 | 权重建议 | 评分依据 |
|:-----|:---------|:---------|
| 合约安全 | 高 | 权限放弃、税率、owner 函数 |
| 流动性质量 | 高 | LP 锁定、池子深度、锁仓期限 |
| 持币分布 | 高 | 前 10 占比、dev 持仓、关联地址 |
| 交易活跃度 | 中 | 成交笔数、买卖平衡、独立钱包数 |
| 社交热度 | 中 | 真实用户、增长曲线、KOL 质量 |
| 叙事强度 | 中 | 是否有可传播的梗/主题/事件 |

规则示例：**总分低于阈值不进；合约安全或流动性质量任一为 0，直接否决（一票否决）。**

权重和阈值先给一版经验值，跑一个月后用真实数据回归调整（见 `docs/07`）。

## 5. 风控规则（资金层面）

- **单笔上限**：单笔投入不超过总资金的 5%（100 USDT → 5 USDT）。
- **同时持仓上限**：同时最多 N 笔（建议 3–5），避免注意力分散。
- **归零不可摊平**：跌了就砍，禁止补仓、禁止越跌越买。
- **日/周熔断**：单日亏损超过阈值（如 30%）当天停手，强制冷静。
- **总熔断**：100 USDT 亏到某个下限（如剩余 30）即停止挑战，进入复盘。
- **不追加**：无论中间是翻倍还是归零，都只投入最初那 100。

## 6. 一票否决清单（任一条命中，直接放弃）

1. Mint 或 freeze 权限未放弃。
2. LP 未锁或锁仓信息查不到。
3. 买卖税异常高或不对称。
4. 试卖失败。
5. 单一地址持有绝大部分 LP 或供应。
6. 找不到任何真实社交痕迹。
7. 流动性深度不足，滑点预估超过既定上限。
