# 02 · 交易原理：AMM、bonding curve、MEV 与交易生命周期

> 目的：理解为什么"看起来一样的一次买入"，成本可以差几倍，以及为什么散户天然慢。
> 更新日期：2026-10-03。具体参数以各协议官方文档为准。

## 1. 两种定价机制

### 1.1 Bonding curve（内盘/曲线）

早期 launchpad 通常用一条预设曲线定价：买的人越多，价格沿曲线上升；卖则沿曲线下降。市值小的时候，很小的买盘就能推动价格大幅上涨，这是"早期倍数大"的数学来源，也是"卖不出去就砸穿"的来源。

关键特征：

- 价格由曲线与当前持仓决定，不依赖外部 LP。
- 总有买/卖两个方向，理论上可卖——但要小心合约层面的限制（见 `03`）。
- 曲线走完（达到某个市值）后"毕业"，转入 AMM 池。

### 1.2 AMM：恒定乘积

主流 AMM 用 `x * y = k` 定价（x、y 为池中两种资产数量）。由此可得：

- **价格影响 / 滑点**：你的单子相对池子越大，成交均价越差。
- 池子越浅，滑点越恐怖。小额的优势在这里体现。
- 深度是相对的：同一个 5 USDT 单子，在深池里几乎无滑点，在浅池里能打出两位数百分比。

必须记住的近似：**滑点大致与"你的单子 / 池子规模"同量级**。交易前先估算池子深度。

## 2. 成本的完整构成

一次买入的真实成本远不止"币价"：

| 成本项 | 说明 | 占比特点 |
|:-------|:-----|:---------|
| 平台/协议费 | launchpad 或 AMM 收取 | 固定比例 |
| LP 费 | 给流动性提供者 | 固定比例 |
| Priority fee | 给验证者的优先费 | 高峰期可涨很多倍 |
| Jito tip 等加速费 | 打包加速 | 可选，但竞价激烈 |
| 滑点 | 成交价差异 | 与池子深度、你的单子相关 |
| 失败交易成本 | 交易失败仍可能付手续费 | 被抢跑时常见 |
| 价差/抽税 | 部分代币买卖抽税 | 可高得离谱 |

**推论**：小额高频在 Solana 才成立，因为基础 gas 极低。同样的打法放到高 gas 链上，成本会直接吃掉彩票。

## 3. MEV 与三明治

MEV（最大可提取价值）指通过调整交易顺序能获得的利润。对散户最相关的是**三明治攻击**：

1. 攻击者看到你的买入。
2. 在你之前买入，推高价格。
3. 你以更差的价格成交。
4. 攻击者在你之后卖出，吃掉差价。

防御思路：控制单笔价格影响、设置合理滑点上限、必要时走私有通道/打包服务。**但在 meme 池这种浅流动性场景，最好的防御是单子足够小、并且不要在流动性极差时硬打大单。**

## 4. 一笔交易的完整生命周期（Solana）

```
构造交易 → 签名 → 提交到 RPC → RPC 转发给当前 leader
   → leader 打包出块 → 广播 → 确认 (confirmed) → 最终确定 (finalized)
```

对散户的意义：

- 你提交交易到"上链"之间有一段竞争窗口，机器人就在这段窗口里抢跑。
- 失败/丢弃的交易不一定免费，重试还会叠加成本。
- 判断"到账/成交"要看链上确认状态，不能只看终端界面。

## 5. 幂律分布：为什么退出规则和股票相反

meme 收益是**极端幂律**：少数标的贡献绝大部分收益，多数归零。由此推出两条反直觉但正确的事：

1. **必须严格砍亏损**——归零是不可逆的，不能"等回本"。
2. **必须让盈利奔跑**——2 倍就跑，会系统性错过那 1% 的百倍，而百倍正是唯一能覆盖全部亏损的东西。

组合起来就是本项目退出规则的核心：**亏损快速止损，盈利分批止盈但保留尾部仓位**（见 `docs/05`）。
