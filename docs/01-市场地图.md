# 01 · 市场地图：Solana meme 生态分层与生命周期

> 目的：先搞清楚钱在哪个环节流动、谁是你的对手，再谈打法。
> 更新日期：2026-10-03。生态变化很快，下文提到的平台与工具需自行核验现状。

## 1. 生态分层

一个 meme 币从诞生到被交易，会经过这几层。每一层的参与者不同，edge 也不同。

| 层 | 作用 | 代表 | 谁在这层赚钱 |
|:---|:-----|:-----|:-------------|
| 发行层 | 一键发币、bonding curve 冷启动 | pump.fun 类平台、其他 launchpad | 平台（抽发行/交易费）、早期 dev |
| 流动性层 | 提供 AMM 池与报价 | Raydium、Meteora、Orca | LP、做市方 |
| 聚合/执行层 | 路由最优路径、下单 | Jupiter 及各类交易终端 | 聚合器、终端（抽费）、抢跑者 |
| 基础设施层 | RPC、打包、加速 | RPC 服务商、Jito 类打包 | RPC、验证者/打包方 |
| 数据层 | 行情、持仓、风险数据 | DexScreener、Birdeye、Rugcheck、Bubblemaps、区块浏览器 | 数据商（订阅费） |
| 传播层 | 注意力分发 | X/Twitter、Telegram、TikTok | KOL、喊单者 |

**关键结论**：散户处在食物链末端。同一个池子里，你的对手是低延迟机器人、做市方、内部人（dev/私募/捆绑地址）和 KOL。你的优势只可能来自"信息更早"或"筛选更好"，不可能来自"手更快"。

## 2. 生命周期与各阶段的赔率

一条 meme 币的典型轨迹：

```
[发币] → [bonding curve / 内盘] → [毕业上 AMM] → [热度扩散] → [见顶] → [阴跌或归零]
   M0          M1                    M2           M3          M4        M5
```

| 阶段 | 特征 | 潜在倍数 | 主要风险 | 适合谁 |
|:-----|:-----|:---------|:---------|:-------|
| M0 刚发币 | 无流动性、无社区、dev 未知 | 极高（百倍以上） | 秒级归零、貔貅、钓鱼 | 机器人、内部人 |
| M1 内盘曲线 | 市值小、价格随买盘走高 | 高（10x+） | 曲线走不完、dev 撤 | 快手 + 严格筛选 |
| M2 刚毕业 | 有真实池子、有基本数据可查 | 中（3–10x） | 假毕业、流动性未锁 | 本研究的主战场 |
| M3 热度期 | 数据齐全、社区活跃 | 低（1.5–3x） | 接盘、顶部 | 追热点、做波段 |
| M4–M5 顶部后 | 流动性衰减 | 负 | 阴跌、抽池 | 不建议 |

**策略取舍**：越早赔率越高、归零率越高、对速度要求越高。以本项目的条件（无低延迟基建、小额、娱乐导向），合理定位在 **M1 后段到 M2**：既能查数据、又不至于完全拼不过机器人。

## 3. 参与者的真实优势

- **Sniper bots**：监听内存池/新池事件，毫秒级入场，成本和速度都不是散户能比的。
- **Inside（dev/私募/捆绑钱包）**：成本接近零，任何价位卖出都是利润。这是最大的对手盘。
- **做市 / MEV**：吃滑点、吃三明治，赚的是确定性的钱。
- **KOL**：赚的是喊单带来的流量，不一定自己持仓。
- **散户（你）**：唯一能积累的优势是**筛选质量 + 纪律 + 记录**。

## 4. 本项目的定位

1. 承认速度劣势，不参与 M0 抢跑。
2. 用链上数据做**过滤**，把归零概率从"行业平均"往下压。
3. 用**幂律思维**做退出：亏损立刻砍，盈利让它跑。
4. 用**记录**把每一笔变成数据点，一个月后能回答"这套打法值不值"。
