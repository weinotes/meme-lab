# 08 · 风险与合规

> 目的：把风险摊开讲清楚，尤其是那些"不会亏钱但会更麻烦"的风险。
> 更新日期：2026-10-03。**本文不是法律意见，请自行咨询专业人士。**

## 1. 四类风险

### 1.1 资金风险

- meme 币绝大多数会归零，100 USDT 全额亏损是**基准预期**而非意外。
- 挑战目标（1 个月 100 倍）概率极低，属于娱乐性目标。

### 1.2 技术风险

- 交易失败、被抢跑、滑点失控、RPC 宕机，都可能造成非预期损失。
- 预警系统的判断可能出错（误报/漏报），不能作为唯一决策依据。
- 第三方数据源可能延迟或错误。

### 1.3 安全风险（最容易造成不可逆损失）

- **钱包被清空**：meme 圈最常见的意外不是买错币，是签了恶意合约或授权导致钱包被掏空。
- 钓鱼网站、假终端、假机器人、假客服，专门针对新手。
- 一旦私钥泄露，资金无法追回。

**钱包安全 SOP**：

1. 使用**专用 burner 钱包**，与主钱包、常用钱包完全隔离。
2. 该钱包只放本次挑战的 100 USDT，不放入任何其他资产。
3. 不签不认识的合约、不点来源不明的链接、不装来源不明的机器人。
4. 每次授权后及时 revoke。
5. 助记词/私钥离线保存，绝不截图、绝不上传、绝不发给任何人。
6. 交易只在官方或公认的终端进行。

### 1.4 合规风险

- 中国大陆对加密货币交易及相关活动有严格限制，个人参与存在法律与政策风险。
- 部分地区对预测市场有专门监管（如美国对部分平台的准入限制），跨境访问可能违规。
- 若涉及刷量、对敲、拉盘等行为，可能触犯市场操纵相关法律，性质远超"交易亏损"。
- 若未来对外提供信号/工具/代管资金，还会涉及牌照、税务、反洗钱等义务。

**原则**：只用自有小额资金做个人研究；不对他人募资、不代管资金、不提供投资建议、不对外售卖信号。

## 2. 事故预案

| 事故 | 处理 |
|:-----|:-----|
| 怀疑私钥泄露 | 立即把剩余资产转移到新钱包，废弃旧钱包 |
| 授权异常 | 立即 revoke 所有可疑授权 |
| 误入钓鱼站 | 立即转移资产、检查授权、更换钱包 |
| 单日大幅亏损 | 触发熔断，当天停止交易，冷静复盘 |
